# 🤖 AI Student Performance Prediction System

## 📌 Project Overview

The AI Student Performance Prediction System is a machine learning project that predicts a student's expected final marks and performance level based on academic factors such as study hours, attendance, assignment scores, and previous marks.

This project was developed using Python and machine learning techniques.

## 🎯 Objective

The main objective of this project is to use student academic data to predict future performance and identify whether a student's performance is Excellent, Good, Average, or Needs Improvement.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning
- Linear Regression

## 📊 Dataset

The dataset contains the following information:

- Study Hours
- Attendance Percentage
- Assignment Score
- Previous Marks
- Final Marks

## ⚙️ How It Works

1. Student data is loaded using Pandas.
2. The data is analyzed using Pandas and NumPy.
3. Data visualization is performed using Matplotlib.
4. The dataset is divided into training and testing data.
5. A Linear Regression model is trained using Scikit-learn.
6. The model predicts the expected final marks.
7. The predicted marks are classified into performance categories.

## 🤖 Machine Learning Model

### Linear Regression

Linear Regression is used to predict the student's final marks based on the input features.

### Input Features

- Study Hours
- Attendance
- Assignment Score
- Previous Marks

### Output

- Predicted Final Marks
- Performance Category

## 📈 Performance Categories

| Marks | Performance |
|---|---|
| 80 or above | Excellent |
| 60–79 | Good |
| 40–59 | Average |
| Below 40 | Needs Improvement |
